# Create table

## ✅ Sample Syntax (Without Constraints)
```sql
CREATE TABLE table_name (
    column1 data_type,
    column2 data_type,
    column3 data_type,
    ...
);
```
## 🔁 2. Rename Table
```sql
RENAME TABLE old_table_name TO new_table_name;
```

## 🧨 3. Drop Table (Delete Table Completely)
```sql
DROP TABLE table_name;
```
