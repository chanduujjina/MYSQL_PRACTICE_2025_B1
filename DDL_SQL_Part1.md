# DDL -> Data Definition Language
## 🔹 1. Create a Database
### ✅ Command:
```sql
CREATE DATABASE {Database Name};

```
## 🔹 2. Use a Database
### ✅ Command:

```sql
USE {Database Name};

```
## 🔹 3. List Databases
```sql
SHOW DATABASES;
```

## 🔹 4. Change Database
```sql
USE other_database;
```
